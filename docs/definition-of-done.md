# Definition of Done

A story is considered Done when:

- All acceptance criteria are satisfied.
- New domain behavior is developed test-first when practical.
- Appropriate automated tests exist for new behavior.
- Existing automated tests remain green.
- Code is formatted and linted according to the project standards.
- No known regression is introduced.
- The completed behavior can be demonstrated through the application when applicable.
- Any intentional deviations from the story are documented in the issue or pull request.
- The developer can explain the important design and implementation decisions.

## Testing Philosophy

The goal is confidence in behavior, not an arbitrary coverage percentage. Prefer tests that document game rules and observable behavior over tests of implementation details.
